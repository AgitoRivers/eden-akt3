Kampf lesen statt rechnen

Probier jede Parade hier aus. Leertaste (oder Klick auf die Bühne) = parieren, D = ausweichen, Enter = Start. Der Gegner leuchtet 1 Sekunde auf (hell = parieren, blau = ausweichen). Parieren ist eine Leiste, Ausweichen ein Kreis, der sich auf den Zielring zusammenzieht. Es ist derselbe Code wie im Spiel.

Spieltest: ändern die Finten die Siegquote?

Bot-Spieltest, 6 Spielertypen × 3 Seeds, vorher (master) und nachher (mit Finten). Der Bot trifft eine Finte schlechter: unbekannte Art perfekt ×0,5 / gut ×0,75, im Bestiarium ×0,85 / ×0,95. Das ist geschätzt, nicht gemessen.

Urteil: keine messbare Verschiebung (gesamt 86 % → 88 % Siege, 174 → 161 Niederlagen, das liegt im Rauschen, weil die Läufe unterschiedlich weit kommen). Die Finten sitzen meist auf Spezialangriffen, die selten kommen, und nach der ersten Parade kennt man den Rhythmus. Engster Kampf bleibt Hafen-Hunde (34 % → 35 %), der hat nur beim Feral Dog eine Finte. Echte Spieler drücken bei einer Finte vermutlich öfter zu früh als der Bot; das muss ein Mensch prüfen.

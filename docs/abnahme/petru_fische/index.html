Petrus Fisch-Sätze

20 Zeilen, je eine pro Fischart. Petru sagt sie beim ersten Verkauf dieser Art an ihn; danach steht der Satz als seine Notiz im Journal (vorher: „Ask Petru about it.“). Aufbau: was der Fisch ist · was ihn besonders macht · warum er so viel zahlt (Stufe 1 wenig, 2 fair, 3 gut). Petru zahlt 50 / 65 / 80 % je Stufe (+5 % je Vertrauensstufe), Lola immer 60 %. Abgenommen und vertont (28.10.).

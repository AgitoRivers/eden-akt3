# Beziehungskurve

Commit f4419f0b, Stufen-Abstand wie im Spiel. Erzeugt von `tests/spieltest_kurve.py`: 3 Seeds je Spieler, offline ohne Modell, gebaut bis Tag 21.

**So lesen:** Die Bots nutzen jede Chance, die Zahlen sind also eine Obergrenze. Ein Mensch ist langsamer. Der Bot wählt Event-Antworten nach dem sichtbaren Text, auch der Ein-Frau-Spieler sammelt dabei Punkte bei den anderen. Werte: Median über die Seeds, „–“ = in der Mehrheit der Läufe nicht erreicht.
